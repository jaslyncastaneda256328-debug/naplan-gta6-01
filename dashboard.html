GTA VI Twitch CCU forecast — practice dashboard

Entry for gta6-twitch-ccu-forecast-01 (make.fun). The program forecasts Twitch concurrent viewers in the “Grand Theft Auto VI” category for hours 2–24 of release day 2026-11-19 (UTC), as five quantiles an hour, from the hour-1 print. Model: per-hour quadratic regression on ln(hour-1 print) plus the pre-launch baseline, fitted from the case's own comparables at run time. Full reasoning: MODEL.md.
